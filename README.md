# CNRobot · v0.1
用国产多模态模型驱动 RoboDojo 双臂，在一次失败后形成可复查的程序改进。首个任务是 stack_bowls。此版本交付实验协议和离线验收程序，真实适配由目标机器完成。尚无本项目成功率。

## 五分钟复刻记录流程
需要 Python 3.10+。执行 python cnrobot.py example.json 。预期输出 fixture，0/1，first_failure=lift。示例是人为构造的抓空记录。随后阅读 PROTOCOL.md，复制 example.json 的字段到自己的运行目录，替换实际模型、提交、种子、布局、原生回执与动作数。示例和实测分开存储。
## 如何贡献
每次改动关联一个失败记录、一条可证伪假设和父版本。提交程序、匿名配置、指标和视频清单。凭据通过运行机环境变量传入。大录像、模型文件、私有服务地址和原始会话留在运行机。研究结果以独立初态的原生终态为准。
## 阅读顺序
1. PROTOCOL.md 的 M0–M3 对应接线、探索、修复、迁移。
2. cnrobot.py 展示记录字段、模型限制和最小验收。
3. 先完成一个可复现实验，再扩展新的任务适配器。

首个任务的具体执行与无人值守续跑规则见 [叠碗任务包 v0.3](tasks/stack_bowls/README.md)。
